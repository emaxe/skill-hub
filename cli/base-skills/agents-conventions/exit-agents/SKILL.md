# Выход из режима agents-conventions

Полная подготовка рутовой папки проекта к работе без конвенции
[agents-conventions](../agents-conventions/SKILL.md): миграция скиллов и правил обратно
в формат целевого агента, проверка структуры.

## Цель

Безопасно вывести проект из режима `agents-conventions`:
- Скопировать пользовательские скиллы из `.agents/skills/` в директорию целевого агента
- Скопировать правила из `.agents/rules/` в формат целевого агента
- Перенести ключевые правила из `AGENTS.md` в конфиг целевого агента (при необходимости)
- НЕ удалять `.agents/`, симлинки и тонкие указатели — это выполнит CLI автоматически

Все операции идемпотентны: если артефакт уже существует — пропустить.

## Подготовка

Перед началом определи целевой агент из сообщения запуска (например, "Target agent: claude-code").
Если целевой агент не указан — спроси пользователя.

## Алгоритм

### 1. Проверка текущей структуры

Убедись, что:
- Директория `.agents/` существует
- `AGENTS.md` существует в корне проекта
- Симлинки `.claude/skills`, `.github/skills`, `.cursor/skills` указывают на `.agents/skills`

Если структура нарушена — сообщи об этом и предложи продолжить с тем, что есть.

### 2. Инвентаризация пользовательских скиллов

Найти все скиллы в `.agents/skills/` — это директории, содержащие `SKILL.md`.

Исключить bootstrap-скиллы:
- `agents-conventions`
- `init-agents`
- `exit-agents`

Пользовательские скиллы — все остальные.

### 3. Миграция скиллов в директорию целевого агента

Определи целевую директорию скиллов в зависимости от агента:
- `claude-code` → `.claude/skills/`
- `cursor` → `.cursor/skills/`
- `copilot` → `.github/skills/`

Для каждого пользовательского скила:

```
если {target}/skills/{skill-name}/ НЕ существует (или это симлинк на .agents/skills):
    скопировать папку .agents/skills/{skill-name}/ в {target}/skills/{skill-name}/
иначе:
    пропустить (скил уже есть в целевой директории)
```

Примечание: после удаления симлинка CLI скиллы будут недоступны через `{target}/skills/`.
Копирование гарантирует их сохранность.

### 4. Миграция правил из .agents/rules/

Найти все `.md` файлы в `.agents/rules/`.

Определи целевой формат в зависимости от агента:

#### claude-code
Правила хранятся как обычные `.md` файлы, доступные агенту через контекст проекта.
Для каждого правила из `.agents/rules/{name}.md`:
- Если `.claude/{name}.md` не существует — скопировать туда

#### cursor
Правила — файлы `.mdc` в `.cursor/rules/`.
Для каждого правила из `.agents/rules/{name}.md`:
- Создать `.cursor/rules/{name}.mdc` со стандартным frontmatter если не существует:

```
---
description: {описание из файла или имя файла}
alwaysApply: false
---
{содержимое правила}
```

#### copilot
Правила — файлы `.instructions.md` в `.github/instructions/`.
Для каждого правила из `.agents/rules/{name}.md`:
- Создать `.github/instructions/{name}.instructions.md` со стандартным frontmatter если не существует:

```
---
applyTo: "**"
---
{содержимое правила}
```

### 5. Обработка AGENTS.md

Прочитай `AGENTS.md`.

Если в `AGENTS.md` есть inline-правила (не только ссылки на файлы в `.agents/rules/`):
- Для `claude-code`: предложи добавить их в `.claude/CLAUDE.md` (или создать его, если нет)
- Для `cursor`: предложи добавить их в `.cursor/rules/project-rules.mdc`
- Для `copilot`: предложи добавить их в `.github/instructions/project-rules.instructions.md`

Если `AGENTS.md` содержит только ссылки — ничего не делать, правила уже мигрированы в шаге 4.

### 6. Финальная проверка

Проверить что всё готово к передаче управления CLI:
- Все пользовательские скиллы скопированы в `{target}/skills/`
- Все правила скопированы в формат целевого агента
- `.agents/` НЕ удалена (это сделает CLI)
- Симлинки НЕ удалены (это сделает CLI)
- Тонкие указатели НЕ удалены (это сделает CLI)

Вывести краткий отчёт:
- Сколько скиллов мигрировано
- Сколько правил мигрировано
- Что было пропущено и почему

## Ограничения

Скилл выполняет только миграцию пользовательского контента. Структурную очистку
(удаление симлинков, тонких указателей, директории `.agents/`) выполняет CLI-команда
`skill-hub agents-conventions disable` автоматически после завершения этого скилла.

## Использование

Скилл вызывается автоматически при переключении агента с `agents-conventions` на
другой агент через TUI или CLI. Можно также запустить вручную для проверки готовности
к выходу из режима.
