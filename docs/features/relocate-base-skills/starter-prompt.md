# Стартовый промпт для реализации фичи «Перенос базовых скиллов»

Скопируй целиком и вставь в новую сессию.

---

Реализуй фичу **Перенос базовых скиллов** по подготовленной документации.

## Документация

- Спецификация: `docs/features/relocate-base-skills/spec.md` — прочитай перед началом
- План: `docs/features/relocate-base-skills/plan.md` — следуй порядку задач, секции «Стратегия выполнения» и «Ревью после каждого шага»
- Чеклист: `docs/features/relocate-base-skills/checklist.md` — отмечай прогресс

## Инструкции

1. Прочитай spec.md, plan.md и checklist.md целиком.
2. Создай/переключись на ветку `feature/relocate-base-skills` (базовая ветка для merge: `update`).
3. Отметь в checklist.md пункты «Подготовка» как выполненные.
4. Выполняй задачи согласно **стратегии выполнения** и зависимостям в plan.md: `sequential` — строго по порядку; `parallel-same` — задачи #3 и #4 можно выполнить параллельно (разные файлы, нет пересечений).
5. После **каждой** задачи: ревью по plan.md и spec.md; убедись, что нет конфликта с параллельными задачами (общие файлы, противоречивая логика). Если задачу делал субагент — проверь результат перед следующим шагом.
6. После выполнения задачи — отметь её в checklist.md (`[x]`).
7. Запусти указанную для задачи проверку.
8. Коммить после каждого логического блока задач.
9. По завершении — отметь «Финализация» в checklist.md и обнови статус в README.md на `Done`.
10. Если что-то непонятно — спроси, не додумывай.

## Ключевые моменты реализации

- **`installBootstrapSkills()`**: разделить на два пути — `agents-conventions` → `.agents/skills/` (как раньше), `init-agents`/`exit-agents` → `path.join(os.homedir(), '.skill-hub', 'bootstrap', skillName)`. Для init/exit НЕ регистрировать в registry.
- **Промпты**: `INIT_PROMPT` и `EXIT_PROMPT` сейчас — статические строки. Заменить на функции, формирующие путь через `path.join(os.homedir(), '.skill-hub', 'bootstrap', '{name}', 'SKILL.md')`. Обновить `AUTO_ANALYSIS_ARGS` / `EXIT_ARGS` соответственно (тоже в функции).
- **`disableConventions()`**: в секции удаления bootstrap-скиллов — удалять только `agents-conventions` из `.agents/skills/`, не трогать `~/.skill-hub/bootstrap/`.
- **Поле `Базовая ветка для merge`** в README.md не менять без причины — по нему скилл feature-accept подставляет цель слияния.
