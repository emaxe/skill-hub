## Краткое описание

Перенести базовые скиллы conventions-режима (`exit-agents`, `init-agents`) из `.agents/skills/` в отдельное расположение, чтобы они не смешивались с обычными пользовательскими скиллами. Весь функционал работы с ними должен сохраниться.
