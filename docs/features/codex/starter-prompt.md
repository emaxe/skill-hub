# Стартовый промпт для реализации фичи «Подключение Codex»

Скопируй целиком и вставь в новую сессию.

---

Реализуй фичу **Подключение Codex** по подготовленной документации.

## Документация

- Спецификация: `docs/features/codex/spec.md` — прочитай перед началом
- План: `docs/features/codex/plan.md` — следуй порядку задач, секции «Стратегия выполнения» и «Ревью после каждого шага»
- Чеклист: `docs/features/codex/checklist.md` — отмечай прогресс
- Предварительный план (справочно): `docs/plans/codex-agent-support.md` — детали принятых решений

## Контекст

Codex — CLI-агент от OpenAI, использующий `AGENTS.md` для инструкций. Адаптер работает по аналогии с `CopilotAdapter` — инъекция контента через HTML-маркеры в единый файл `AGENTS.md` (а не отдельные файлы в директории).

Ключевые решения (уже приняты):
- **Project scope:** `.codex/AGENTS.md` (не в корне — конфликт с conventions)
- **Global scope:** `~/.codex/AGENTS.md`
- **platformKey('codex')** возвращает `'claude-code'` — все расширения каталога доступны
- **Детекция:** env var `CODEX_SANDBOX` + директория `.codex/`
- **Главный референс:** `CopilotAdapter` в `cli/src/adapters/copilot.ts`

## Инструкции

1. Прочитай `spec.md` и `plan.md` целиком.
2. Создай ветку `feature/codex` от текущей ветки `SER-5505-windows-codex` и переключись на неё.
3. Отметь в `checklist.md` пункты «Подготовка» как выполненные.
4. Выполняй задачи согласно **стратегии выполнения** и зависимостям в `plan.md`:
   - Задачи #1 → #2 → #3 → #4 → #5 — строго последовательно (ядро типов и адаптер).
   - Задачи #6, #7, #8, #9 — параллельно через субагентов (CLI/MCP, TUI, conventions — разные файлы, нет пересечений).
   - Задачи #10, #11, #12, #13 — параллельно через субагентов (тесты, скилл, документация).
   - Задача #14 — финальная проверка после всех остальных.
5. После **каждой** задачи: ревью по `plan.md` и `spec.md`; убедись, что нет конфликта с параллельными задачами (общие файлы, противоречивая логика). Если задачу делал субагент — проверь результат перед следующим шагом.
6. После выполнения задачи — отметь её в `checklist.md` (`[x]`).
7. Запусти указанную для задачи проверку (`npm run build` / `npm test`).
8. Коммить после каждого логического блока задач.
9. По завершении — отметь «Финализация» в `checklist.md` и обнови статус в `README.md` на `Done`.
10. Если что-то непонятно — спроси, не додумывай.
