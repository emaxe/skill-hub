# Стартовый промпт для реализации фичи «AGENTS-CONVENTIONS Mode»

Скопируй целиком и вставь в новую сессию.

---

Реализуй фичу **AGENTS-CONVENTIONS Mode** по подготовленной документации.

## Документация

- Спецификация: `docs/features/agents-conventions-mode/spec.md` — прочитай перед началом
- План: `docs/features/agents-conventions-mode/plan.md` — следуй порядку задач, секции «Стратегия выполнения» и «Ревью после каждого шага»
- Чеклист: `docs/features/agents-conventions-mode/checklist.md` — отмечай прогресс

## Контекст

Добавляем новый режим работы `agents-conventions` в skill-hub CLI. В этом режиме расширения устанавливаются в единую `.agents/` директорию и становятся доступны всем AI-агентам (Claude Code, Cursor, Copilot) через симлинки и тонкие указатели. Режим работает только в project scope.

Ключевые решения:
- `'agents-conventions'` — новое значение `AgentName` (4-й адаптер)
- Скиллы → `.agents/skills/{name}/SKILL.md`, агенты/команды/правила → `.agents/rules/{name}.md`
- Source-файлы берутся по логике claude-code (SKILL.md)
- `--global` запрещён при активном режиме
- Инициализация: CLI создаёт структуру + скилл init-agents для AI-агента
- Деактивация: обратная миграция + предложение удалить .agents/

Обязательно изучи конвенцию agents-conventions для понимания структуры: `/Users/maksimklisin/Desktop/_JS/testConv/.agents/skills/agents-conventions/SKILL.md`

## Инструкции

1. Прочитай spec.md, plan.md и checklist.md целиком.
2. Создай ветку `feature/agents-conventions` и переключись на неё.
3. Отметь в checklist.md пункты «Подготовка» как выполненные.
4. Выполняй задачи согласно **стратегии выполнения** и зависимостям в plan.md:
   - `sequential` — строго по порядку
   - `parallel-subagent` — можно вынести параллельным субагентам после выполнения зависимостей (задачи #7–11, #15 — после #3; задачи #13–14 — после #3)
   - `parallel-same` — параллельно в одной сессии
5. После **каждой** задачи:
   - Ревью по plan.md и spec.md
   - Убедись, что нет конфликта с параллельными задачами (общие файлы, противоречивая логика)
   - Если задачу делал субагент — проверь результат перед следующим шагом
6. После выполнения задачи — отметь её в checklist.md (`[x]`).
7. Запусти указанную для задачи проверку (`npm run build` или ручной тест).
8. Коммить после каждого логического блока задач.
9. По завершении — отметь «Финализация» в checklist.md и обнови статус в README.md на `Done`.
10. Если что-то непонятно — спроси, не додумывай.
