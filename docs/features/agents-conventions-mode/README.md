## Краткое описание

Новый режим работы skill-hub, при котором расширения устанавливаются в единую директорию `.agents/` и становятся доступны сразу всем поддерживаемым AI-агентам (Claude Code, Cursor, Copilot) через систему тонких указателей и симлинков. Работает только в project scope.
