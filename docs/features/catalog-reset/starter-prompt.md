# Стартовый промпт для реализации фичи «Очистка расширений при смене репозитория каталога»

Скопируй целиком и вставь в новую сессию.

---

Реализуй фичу **Очистка расширений при смене репозитория каталога** по подготовленной документации.

## Документация

- Спецификация: `docs/features/catalog-reset/spec.md` — прочитай перед началом
- План: `docs/features/catalog-reset/plan.md` — следуй порядку задач, секции «Стратегия выполнения» и «Ревью после каждого шага»
- Чеклист: `docs/features/catalog-reset/checklist.md` — отмечай прогресс
- Исходный анализ проблемы: `docs/plans/changeCatalogRepo.md` — дополнительный контекст

## Инструкции

1. Прочитай `spec.md`, `plan.md` и `checklist.md` целиком.
2. Создай ветку `feature/catalog-reset` от `main` и переключись на неё.
3. Отметь в `checklist.md` пункты «Подготовка» как выполненные.
4. Выполняй задачи согласно **стратегии выполнения** и зависимостям в `plan.md`:
   - **Задача #1** (`fullCatalogReset()` в `git.ts`) — выполни первой, последовательно.
   - **Задачи #2, #3, #4** — можно вынести параллельным субагентам после завершения #1:
     - #2: CLI `config set` — предупреждение + readline + `--yes` (`commands/config.ts`)
     - #3: TUI `SettingsScreen` — Confirm flow (`SettingsScreen.tsx`)
     - #4: Unit-тесты для `fullCatalogReset()` (`git.test.ts`)
   - **Задача #5** — финальная верификация (`npm run build && npm test`) после всех остальных.
5. После **каждой** задачи: ревью по `plan.md` и `spec.md`; убедись, что нет конфликта с параллельными задачами (общие файлы, противоречивая логика). Если задачу делал субагент — проверь результат перед следующим шагом.
6. После выполнения задачи — отметь её в `checklist.md` (`[x]`).
7. Запусти указанную для задачи проверку.
8. Коммить после каждого логического блока задач.
9. По завершении — отметь «Финализация» в `checklist.md` и обнови статус в `README.md` на `Done`.
10. Если что-то непонятно — спроси, не додумывай.

## Ключевые ориентиры

- **Паттерн readline**: скопируй подход из `cli/src/commands/agents-conventions.ts` (функция `askQuestion`)
- **Confirm в TUI**: используй существующий `cli/src/tui/components/Confirm.tsx`
- **Очистка extensions**: `saveProjectExtensions([])` из `cli/src/config.ts`
- **Подсчёт extensions**: `loadProjectExtensions().length` из `cli/src/config.ts`
- **Путь проекта**: `findProjectRoot()` из `cli/src/config.ts`
