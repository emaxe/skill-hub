# Фича: Очистка расширений при смене репозитория каталога

**Slug:** catalog-reset
**Jira:** не привязана

**Базовая ветка для merge:** `main`
**Дата начала:** 2026-04-14
**Статус:** Done

## Краткое описание

При смене `registryUrl` (каталога расширений) через CLI или TUI — очищать записи расширений в проектном конфиге `.skill-hub.json` с предупреждением пользователю, чтобы избежать рассинхрона между конфигом и новым каталогом.
